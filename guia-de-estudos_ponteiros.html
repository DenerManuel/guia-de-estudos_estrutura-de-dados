Tópico 1

1. O que é um Ponteiro (do zero, sem enrolação)

📌 Conceito Uma variável normal guarda um valor (um número, uma letra, etc.).
Um ponteiro é uma variável especial que guarda um endereço de memória — ou seja, o lugar exato onde aquele valor está guardado dentro do computador.
🏠 A analogia definitiva: a Casa e o Morador Imagine uma rua cheia de casas.

• A variável comum é o morador dentro da casa (o valor, por exemplo o número 10).
• O ponteiro é um papelzinho com o endereço da casa escrito nele (por exemplo, "Rua 0x1000, casa 4").

Muito importante: o endereço da casa NÃO é o morador! Escrever "Rua 0x1000" no papel não é a mesma coisa que a pessoa que mora lá. Guardar o endereço é diferente de guardar o valor.

Por que usar ponteiros? (para que servem de verdade)

  • Fazer funções alterarem variáveis de fora: sem ponteiro, a função só recebe uma cópia e não consegue mudar a variável original.
  • Trabalhar com vetores (arrays) e strings de forma eficiente: em vez de copiar tudo, passamos só o endereço do primeiro elemento.
  • Ser a base da alocação dinâmica de memória (malloc/free): criar espaços de memória na hora em que o programa está rodando.
  • Ser o alicerce das estruturas de dados: listas encadeadas, pilhas, filas e árvores só existem porque existem ponteiros.
💚 Dica de estudo Sempre que bater dúvida, pergunte a si mesmo: "Estou falando do MORADOR (valor) ou do PAPEL COM O ENDEREÇO (ponteiro)?". Essa única pergunta resolve 90% das questões de prova.
Tópico 2

2. Operadores e Notação (o coração do assunto)

Os dois operadores que você precisa dominar

OperadorNomePergunta que ele respondeExemplo
& Operador de endereço (address-of) "Onde você mora?" → pega o endereço da variável &x → endereço de x
* Operador de conteúdo (desreferência) "O que tem dentro dessa casa?" → acessa/altera o valor guardado naquele endereço *p → valor que está no endereço guardado em p

Tabela de notação (decore esta tabela!)

Suponha o código abaixo, com endereços fictícios só para facilitar o entendimento:

int x = 10;      // a variável x mora no endereço 0x1000
int *p = &x;     // o ponteiro p mora no endereço 0x2000 e guarda 0x1000
ExpressãoO que significa (em palavras simples)Valor no exemplo
xO valor guardado dentro da variável x (o morador)10
&xO endereço de memória onde x está guardado (onde a casa fica)0x1000
pO valor que está dentro do ponteiro p — que é o endereço de x0x1000
*pO conteúdo que existe no endereço guardado dentro de p (abrir a casa e ver o morador)10
&pO endereço de memória onde o próprio ponteiro p está guardado0x2000
🚨 Pegadinha clássica de prova O símbolo * tem dois papéis diferentes:
• Na declaração (int *p;) ele diz "p é um ponteiro".
• No meio do código (*p = 50;) ele diz "o conteúdo do endereço apontado por p".
São coisas diferentes com a mesma carinha. Leia sempre o contexto!
Tópico 3

3. Declaração, Inicialização e Segurança com NULL

Como declarar

int *p;    // leia em voz alta: "p é um ponteiro que aponta para um inteiro"

Como inicializar (dar um endereço válido para ele)

int x = 10;      // cria a variável comum, com o valor 10
int *p = &x;     // p agora guarda o ENDEREÇO de x (p aponta para x)
🚨 PERIGO: o ponteiro selvagem (wild pointer) Quando você escreve apenas int *p;, o ponteiro não recebe nenhum endereço válido. Ele fica com um "lixo" que estava na memória.

Se você tentar ler ou escrever *p nesse estado, o programa pode travar (crashar), corromper dados ou se comportar de forma totalmente imprevisível.

Regra de ouro: nunca use um ponteiro antes de dar um endereço válido a ele.

O ponteiro que não aponta para lugar nenhum: NULL

int *p = NULL;   // p existe, mas aponta para "lugar nenhum" (endereço inválido)
💚 Dica de ouro: sempre verifique antes de usar 
if (p != NULL) {
    *p = 100;     // só mexe se o ponteiro realmente aponta para algum lugar válido
}
Isso evita que o programa quebre. É a mesma ideia de conferir se o papelzinho do endereço está em branco antes de sair dirigindo até lá.
Tópico 4

4. Modificando Variáveis e Funções (Passagem por Referência)

Alterando o valor de x sem tocar em x

int x = 10;
int *p = &x;

*p = 50;      // "vá até a casa apontada por p e coloque 50 lá dentro"

printf("%d", x);   // imprime 50 — x mudou, mesmo sem escrevermos x = 50!

Passagem por valor vs Passagem por ponteiro

❌ Passagem por valor (não muda o original)

void somaUm(int n) {   // recebe uma CÓPIA do valor
    n = n + 1;         // muda só a cópia, o original fica igual
}

int main(void) {
    int x = 10;
    somaUm(x);         // passa só o valor 10
    printf("%d", x);   // imprime 10 — NÃO mudou!
    return 0;
}

✅ Passagem por ponteiro (muda o original)

void incrementa(int *n) {   // recebe o ENDEREÇO
    (*n)++;                 // vai até a casa e aumenta o valor de dentro
}

int main(void) {
    int x = 10;
    incrementa(&x);         // passa o ENDEREÇO de x
    printf("%d", x);        // imprime 11 — MUDOU de verdade!
    return 0;
}
🏠 Analogia para fixar Passagem por valor = você tira uma fotocópia do documento e entrega. O outro pode rabiscar a cópia à vontade — o seu original continua intacto.

Passagem por ponteiro = você entrega o endereço da sua casa e a chave. A outra pessoa vai lá e mexe no original de verdade.
🚨 Pegadinha de prova Se a função é void incrementa(int *n), a chamada precisa ser incrementa(&x); — com o &!
Se você escrever incrementa(x);, o compilador reclama (ou pior, o programa quebra). A função quer um endereço, não um número.
Tópico 5

5. Ponteiro para Ponteiro, Vetores e Strings

Ponteiro para ponteiro (**pp)

É um papelzinho que guarda o endereço de outro papelzinho. Simples assim.

int x = 10;
int *p = &x;        // p aponta para x
int **pp = &p;      // pp aponta para p

printf("%d", **pp); // imprime 10 — dois "asteriscos" para chegar no valor final
ExpressãoO que éValor no exemplo
xO valor guardado em x10
pO endereço de x0x1000
*pO valor de x (abriu a casa uma vez)10
ppO endereço de p0x2000
*ppO valor de p, ou seja, o endereço de x0x1000
**ppO valor de x (abriu a casa duas vezes)10

Vetores e Aritmética de Ponteiros

📌 Conceito essencial O nome de um vetor é, na prática, um ponteiro para o primeiro elemento dele (&v[0]).
Por isso, v[i] é exatamente a mesma coisa que *(v + i). 
int v[3] = {5, 10, 15};

printf("%d", v[1]);        // 10
printf("%d", *(v + 1));    // 10  ← idêntico!

// Somar 1 a um ponteiro NÃO soma 1 no endereço bruto:
// ele "anda uma casa" inteira na memória (no caso de int, 4 bytes).
💚 Dica: pular de casa em casa Se v está no endereço 0x1000 e cada int ocupa 4 bytes:
• v + 0 → 0x1000 → v[0]
• v + 1 → 0x1004 → v[1]
• v + 2 → 0x1008 → v[2]

Strings com Ponteiros

Em C, uma string é um vetor de caracteres que termina com o caractere especial '\0' (o "fim da linha").

char nome[] = "ADS";
char *p = nome;               // p aponta para o primeiro caractere

while (*p != '\0') {          // enquanto não chegar no fim da string
    printf("%c", *p);         // mostra o caractere atual
    p++;                      // anda uma casinha para o próximo
}
🚨 Pegadinha: p++ é diferente de (*p)++ • p++ → faz o ponteiro andar para a próxima posição da memória.
• (*p)++ → aumenta o valor guardado na posição atual (por exemplo, 'A' viraria 'B').
Os parênteses mudam tudo!
Tópico 6

6. Pegadinhas de Prova (onde todo mundo perde ponto)

🚨 Pegadinha 1: confundir p (endereço) com *p (valor) Dentro de funções que recebem ponteiros, é comum escrever errado: 
if (a > b)      // ERRADO! Compara ENDEREÇOS de memória, não os números
if (*a > *b)    // CERTO! Compara os VALORES que estão dentro das casas
Esse é o erro mais clássico em questões de "maior valor entre três números".
🚨 Pegadinha 2: trocar valores sem variável temporária Dá para trocar dois valores usando só aritmética com ponteiros: 
*p = *q + *p;   // soma os dois e guarda em p
*q = *p - *q;   // agora q recebe o valor original de p
*p = *p - *q;   // e p recebe o valor original de q
Funciona, mas cuidado: se os valores forem muito grandes pode haver estouro (overflow). Na prova, a versão com variável temporária é a mais segura e aceita.

Exemplo 1

Modificando uma Variável através de um Ponteiro

Objetivo: mostrar que dá para mudar o valor de x sem escrever x = ....

#include <stdio.h>

int main(void) {
    int x = 10;          // variável normal: guarda o VALOR 10
    int *p = &x;         // ponteiro: guarda o ENDEREÇO de x

    printf("Antes:  x = %d\n", x);     // mostra 10

    *p = 50;             // "vá na casa apontada por p e coloque 50 lá dentro"

    printf("Depois: x = %d\n", x);     // mostra 50

    return 0;
}

Passo a passo do que acontece na memória

  1. int x = 10; → o computador reserva uma casinha e coloca 10 dentro. Suponha endereço 0x1000.
  2. int *p = &x; → o computador reserva outra casinha (0x2000) e coloca o endereço 0x1000 dentro dela.
  3. *p = 50; → o programa olha dentro de p, encontra 0x1000, vai até lá e troca o 10 por 50.
  4. Resultado: x vale 50, mesmo sem nunca termos escrito x = 50.
💚 Saída do programa 
Antes:  x = 10
Depois: x = 50
Exemplo 2

Trocando Valores com a Função trocar

Objetivo: trocar o conteúdo de duas variáveis usando passagem por referência.

#include <stdio.h>

// Recebe dois ENDEREÇOS e troca os valores que estão neles
void trocar(int *a, int *b) {
    int temp = *a;   // guarda o valor da casa "a" na caixinha temporária
    *a = *b;         // a casa "a" recebe o valor da casa "b"
    *b = temp;       // a casa "b" recebe o valor guardado
}

int main(void) {
    int x = 3, y = 7;

    printf("Antes:  x = %d | y = %d\n", x, y);

    trocar(&x, &y);  // passamos os ENDEREÇOS de x e y

    printf("Depois: x = %d | y = %d\n", x, y);

    return 0;
}

Encontrando o Maior Valor entre Três Números

Objetivo: comparar valores e não endereços (essa é a pegadinha!).

#include <stdio.h>

int maiorValor(int *a, int *b, int *c) {
    int maior = *a;                  // começa assumindo que o valor de a é o maior

Exemplo 4

Percorrendo Vetores e Strings com *(p + i)

Objetivo: somar dois vetores e depois percorrer uma string usando aritmética de ponteiros.

#include <stdio.h>

int main(void) {
    int v1[3] = {1, 2, 3};
    int v2[3] = {10, 20, 30};
    int resultado[3];
    int *p;

    // Soma dos vetores usando notação de ponteiro
    for (int i = 0; i < 3; i++) {
        *(resultado + i) = *(v1 + i) + *(v2 + i);
    }

    // Percorrendo o vetor resultado com um ponteiro
    p = resultado;                     // p aponta para o primeiro elemento
    for (int i = 0; i < 3; i++) {
        printf("%d ", *(p + i));       // imprime 11 22 33
    }
    printf("\n");

    // Percorrendo uma string caractere por caractere
    char nome[] = "ADS";               // guarda 'A', 'D', 'S', '\0'
    char *s = nome;                    // s aponta para o primeiro caractere

    while (*s != '\0') {               // enquanto não chegar no fim da string
        printf("%c", *s);              // mostra o caractere atual
        s++;                           // anda uma casinha para o próximo
    }
    printf("\n");

    return 0;
}

Resumo para a Véspera da Prova

Leia estes 10 pontos em voz alta, devagar, antes de dormir. Eles resumem todo o assunto.

  • Variável normal guarda valor; ponteiro guarda endereço. O morador é o valor; o papel com o endereço é o ponteiro.
  • &x = "onde você mora?" Pega o endereço da variável x. Sempre com & na frente.
  • *p = "o que tem dentro dessa casa?" Acessa ou altera o valor que está no endereço guardado em p.
  • Declarar é diferente de usar: int *p; apenas diz que p é ponteiro. *p = 10; mexe no conteúdo.
  • Ponteiro selvagem mata o programa. Nunca use *p antes de dar um endereço válido. Use NULL e cheque if (p != NULL).
  • Passagem por valor copia; passagem por ponteiro altera o original. Chame com f(&x) quando o parâmetro for int *n.
  • Dentro de funções com ponteiros, compare *a > *b, nunca a > b. Comparar endereços não tem nada a ver com comparar números.
  • Nome de vetor é ponteiro para o primeiro elemento. Por isso v[i] é exatamente igual a *(v + i).
  • Somar 1 a um ponteiro anda uma "casa" inteira na memória (4 bytes para int), não 1 byte.
  • String em C termina com '\0'. Percorra com while (*p != '\0') { ... p++; }.
💚 Checklist final de 30 segundos Antes de entregar a prova, confira: (1) coloquei & nas chamadas de função? (2) usei * nas comparações dentro da função? (3) todos os ponteiros foram inicializados? (4) os parênteses de *(p + i) estão certos?
