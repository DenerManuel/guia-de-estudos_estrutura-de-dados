Como usar este hub

• Cada módulo é uma página independente com 6 abas internas: Teoria, Exemplos, Código & Memória, Comparações, Resumo e Quiz.

• Recomendo estudar na ordem 1 → 2 → 3 → 4. Cada módulo assume que você já viu o anterior.

• O rodapé de cada módulo tem um quiz interativo. Use-o como autoavaliação antes da prova.

• Dica: para procurar uma palavra em todos os módulos, abra o site publicado e use Ctrl+F dentro de cada um.
